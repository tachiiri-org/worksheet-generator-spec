# 契約：レイアウト → プリント

## 意図

プリント生成において、レイアウトの未解決要素を解決し、不変スナップショットへ落とす規則を固定する。

## レイアウト側の前提（未解決）

- レイアウトはスロット/プレースホルダーを参照しうる。
- レイアウトは素材を直接参照してはならない。

## プリント側の要件（固定）

プリントは以下を満たさなければならない。

- プリントは immutable である。
- プリントは設計図参照を持ってはならない。
- プリントはスロット参照を持ってはならない（解決済みであること）。
- プリントが外部を参照する場合、許されるのは素材参照（素材ID + 内容ハッシュ）のみである。

## 固定レイアウト（プリントレイアウト）に含める実地

プリントレイアウトは、再現に必要な構造情報をすべて含む。

- 用紙規格相当（用紙サイズ・余白など）
- 外側方眼紙（OuterGrid）
- 配置枠の座標・面・枠種別
- コネクタ
- テキスト描画の内部グリッド・枠線・注釈
- 画像描画は素材参照（素材ID + 内容ハッシュ）に落とす

## 禁止

- プリントが設計図IDやテンプレートIDから情報を取得して解釈すること
- プリントがスロットを保持し、後段（配布等）で解決すること

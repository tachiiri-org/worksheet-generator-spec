# 環境設定

## 意図

環境設定 は、環境全体で共有される既定値を表す。

レイアウトや配置枠が個別に指定しない場合に適用される
「基準となる描画前提」を定義する。

これにより、

- レイアウトの個別設定と既定値を分離する
- 出力先（PDF / Slides / Excel 等）が増えても意味論を壊さない
- 公開物の解釈を決定的にする

ことを可能にする。

## 定義

環境設定 は以下を持つ。

- 環境設定ID
- 既定フォント: フォント仕様
- 既定DPI: number

## 非目標

- 設定UIや保存方法（L2/L3）
- 出力先ごとのフォント解決戦略（L2/L3）
- DPIを出力先ごとに動的に変更する仕組み（L2/L3）

## 関係

- レイアウト は 環境設定ID を参照する。
- レイアウト は 既定フォント上書き によって 環境設定 の既定フォントを上書きしうる。
- 配置枠 は フォント上書き によって レイアウト / 環境設定 を上書きしうる。

最終フォントは以下の順で解決される。

1. 環境設定.既定フォント
2. レイアウト.既定フォント上書き
3. 配置枠.フォント上書き

## 不変条件

- 既定DPI は正の数であること。
- 既定DPI は意味解釈上の基準値であり、
  同一公開物に対して解釈が変化してはならない。

## 補足

- 既定DPI は、生成画像の決定性やレンダリング解釈に影響する。
- DPIを変更する場合は、公開物の互換性に注意する必要がある。

# 用紙規格

## 意図

用紙規格 は「用紙サイズのプリセット」を表す。

規格名（A4等）だけでなく、
利用文脈に沿った意味的プリセット
（例: 印刷用 / 画面表示用 / ポスター販売用 / Google Slides標準）を同列に扱う。

余白は印刷や表示の前提に近いため、用紙規格に紐づけて扱う。

## 定義

- 用紙規格ID
- 名称: string
- 用紙サイズ: 用紙サイズ
- 余白: 余白
- 備考?: string

## 非目標

- 用紙プリセットの配布/公開制御（別ドメイン）
- プリンタ依存の最終調整（L2/L3）
- 出力先ごとのスケーリング（L2/L3）

## 関係

- レイアウト は 用紙規格 を参照する。
- 用紙規格 は 用紙サイズ と 余白 を所有する。

## 不変条件

- 名称は環境内で一意であることが望ましい（強制はL2/L3）。
- 用紙サイズの単位は mm とする。
- 余白の単位は mm とする。

## 補足

- 「A4（印刷用）」と「A4（画面用）」のように、同じ寸法でも別プリセットとして扱える。

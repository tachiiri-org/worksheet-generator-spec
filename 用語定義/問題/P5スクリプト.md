# P5スクリプト

## 意図

P5スクリプト は、p5.js による決定的な画像生成スクリプトを表す。
グラフや図形など、教材として必要な図の生成を支援する。

## 定義

- language: "p5js"
- code: string

## 非目標

- 実行環境の仕様（L2/L3）
- ライブラリバージョン管理（L2/L3）
- 外部リソース取得（禁止）

## 関係

- PlaceHolder(Target=ImageGeneratedTarget) は P5スクリプト を所有する。

## 不変条件

- 乱数不可（random等の使用を禁止する前提）
- 外部ネットワークアクセス不可
- 外部ストレージアクセス不可
- 同じ入力条件（paper_spec / grid / dpi / font等）であれば同じ出力になること

## 補足

- 入力境界（テーマ変数・文字列等のパラメータ化）は、必要になった時点で別概念として追加する。
  - 現時点では「固定のコード＋固定の解釈条件」で十分とする。

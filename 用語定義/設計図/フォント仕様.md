# フォント仕様

## 意図

フォント仕様 は、テキストの視覚的表現を指定する抽象である。

出力先（PDF / Slides / Excel 等）の違いを吸収するのではなく、
「どのような文字表現を意図しているか」を固定する。

## 定義

フォント仕様 は以下を持つ。

- 書体名: string
- 太さ: 数値または識別子
- 文字サイズpt: number
- 行間倍率: number

## 責務

- 文字表現の意図を固定する（出力先依存の最終解釈はL2/L3）

## 非目標

- フォント埋め込み
- フォールバック戦略
- 出力先ごとの置換処理

## 不変条件

- 文字サイズpt は正の数。
- 行間倍率 は正の数。

## 関係

- 環境設定 は 既定フォント として フォント仕様 を所有する。
- レイアウト は 既定フォント上書き として フォント仕様 を参照しうる。
- 配置枠定義 は 既定フォント上書き として フォント仕様 を参照しうる。
- 配置枠インスタンス は フォント上書き として フォント仕様 を参照しうる。

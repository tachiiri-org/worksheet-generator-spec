# 座標（Template）

## 意図

座標は、OuterGrid 上の矩形領域を表す。

配置枠定義の位置と大きさを安定化するための値オブジェクトである。

## 定義

- 上端: number
- 左端: number
- 幅: number
- 高さ: number

単位は grid units とする。

## 責務

- OuterGrid 上の領域を示す

## 非目標

- mm/pxへの変換式
- 範囲外や重なり等の検証ポリシー（必要ならL2/L3またはissue化）

## 不変条件

- 値は grid units として解釈される。
- 幅/高さは正の数であること。

## 関係

- 配置枠定義 は 座標 を持つ。

# 実体

## 意図

実体は、配布結果としてスロットに割り当てる「最終データ」を表す。

レイアウトはスロットを意味解釈しないが、
配布はスロットを解決して実体を確定する。

## 定義

実体はタグ付きユニオン（kindによる排他）である。

- kind:
  - テキスト
  - 画像

### kind=テキスト

- 本文: string

### kind=画像

- 素材参照: 素材参照

## 責務

- 配布物の最終データ型を固定する

## 非目標

- 画像生成方式（QR生成等）の具体（L2/L3）
- 素材の保存・権利管理（素材境界）

## 不変条件（one-of）

- kind=テキスト のとき、素材参照は存在してはならない。
- kind=画像 のとき、本文は存在してはならない。
